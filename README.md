# Thirst_Tracker

A simple web-based hydration tracker that helps users monitor daily water intake and maintain healthy hydration habits.

## Problem Analysis

Many students and working professionals become busy and forget to drink enough water throughout the day. This may cause fatigue, reduced concentration, and lower productivity. Users need a quick and simple way to track hydration without interrupting their routine.

## Proposed Solution

Thirst_Tracker allows users to:
- Set a daily water goal
- Add consumed water quickly (+250ml or +500ml)
- Track progress using a progress bar
- View remaining water needed
- Save progress using localStorage

## Technical Approach

The project was developed using:

- **HTML** — Creates the structure of the application (inputs, buttons, progress display)
- **CSS** — Styles the interface and improves user experience
- **JavaScript** — Handles calculations, updates progress, and manages functionality
- **localStorage** — Saves hydration goals and intake data even after refreshing

## Features

✓ Daily goal setter  
✓ Quick-add water buttons  
✓ Progress bar tracking  
✓ Remaining intake calculation  
✓ Persistent storage using localStorage  
✓ Reset functionality
